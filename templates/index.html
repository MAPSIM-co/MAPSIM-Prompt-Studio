۱ کلید دسترسی

                    

                        

                            سرویس‌دهندهٔ این برنامه Google AI Studio (Gemini) است.
                            کلید را از نشانی
                            aistudio.google.com/apikey
                            بگیرید و اینجا وارد کنید.
                        

                        

                            
                            {% if config.api_key_source == "environment" %}
                            
                            

                                
                                کلید فعال از متغیر محیطی ({{ config.api_key_masked }}) — این مقدار در فایل config.json ذخیره نمی‌شود.
                            

                            {% else %}
                            
                            

                                {% if config.has_api_key %}
                                
                                کلید ذخیره‌شده: {{ config.api_key_masked }} — برای نگه‌داشتن، فیلد را خالی بگذارید.
                                {% else %}
                                
                                هنوز کلیدی تنظیم نشده است؛ تا این فیلد خالی است، دکمهٔ «تبدیل کن» خطای کلید می‌دهد.
                                {% endif %}
                                
                            

                            {% endif %}
                            

                                این کلید کجا ذخیره می‌شود و چطور نگاهش کنم؟
                                
    
                                    
  • در فایل config.json کنار برنامه، فقط با دسترسی صاحب فایل (۶۰۰) نوشته می‌شود.
    • 
                                    
  • اگر متغیر محیطی PROMPT_STUDIO_API_KEY یا GEMINI_API_KEY تنظیم شده باشد، آن بر فایل می‌چربد و چیزی روی دیسک ذخیره نمی‌شود.
    • 
                                    
  • صفحه هیچ‌وقت خودِ کلید را نمایش نمی‌دهد؛ تنها چهار نویسهٔ آخر برای تشخیص نشان داده می‌شود.
    • 
                                    
  • این کلید را در اختیار کسی نگذارید و در اسکرین‌شات یا مخزن عمومی منتشر نکنید. اگر جایی فاش شد، در AI Studio کلید را revoke و یکی تازه بسازید.
    • 
                                

                            

                        

                    

                


                

                    
۲ مدل پیش‌فرض

                    

                        این مدل، انتخاب اولیهٔ هر درخواست تازه است. در خود صفحهٔ تبدیل هم می‌توانید برای یک درخواست
                        خاص مدل عوض کنید؛ آنچه اینجا انتخاب کنید برای درخواست‌های بعدی به‌کار می‌آید.
                    

                    

                        
                        
                        

                            
برای دیدن جزئیات مدل، یکی را انتخاب کنید.

                        

                    

                    

                        چطور بهترین مدل را انتخاب کنم؟
                        
    
                            
  • سری Lite — ارزان‌ترین و سریع‌ترین. برای درخواست‌های کوتاه و تعداد بالای تبدیل. جزئیات ریز را ممکن است از دست بدهد.
    • 
                            
  • سری Flash — تعادل کیفیت و هزینه؛ گزینهٔ پیشنهادی این برنامه برای بیشتر کارها.
    • 
                            
  • سری Pro — دقیق‌ترین استدلال برای پرامپت‌های بلند و چندهدفه؛ کندتر و گران‌تر.
    • 
                            
  • اعداد نشان‌داده‌شده (RPM / TPM / RPD) سقف درخواست ثبت‌شده در این برنامه‌اند و سهمیهٔ پولی سرویس‌دهنده متفاوت است.
    • 
                            
  • هزینه‌ها در این رابط به‌صورت سطح نسبی بیان شده‌اند؛ قیمت دقیق هر مدل را در
                                صفحهٔ رسمی قیمت Google
                                ببینید.
    • 
                        

                    

                


                

                    
۳ سیستم پرامپت اختصاصی (اختیاری)

                    

                        
                        
                        

                            
                            
                        

                        

                            

                                این بخش چیست؟
                                «پرامپت سیستم» قواعد بازی را تعیین می‌کند: به مدل می‌گوید چه نقشی داشته باشد،
                                خروجی را چطور بسازد و چه کارهایی ممنوع است. این دستور پیش از درخواست شما به
                                سرویس Google فرستاده می‌شود و روی همهٔ تبدیل‌ها اثر دارد تا وقتی
                                تغییرش بدهید.
                            

                            

                                اگر خالی بگذارید چه می‌شود؟
                                دستور پیش‌فرض خود برنامه استفاده می‌شود: همان متنی که درخواست را به پرامپت
                                انگلیسی ساختاریافته تبدیل می‌کند، اجازه نمی‌دهد فناوری یا شرطی از خودشان اضافه
                                شود، و پاسخ را در قالب JSON برمی‌گرداند تا این صفحه بتواند آن را بخش‌بخش نمایش دهد.
                            

                            

                                چه چیزی بنویسم که کاربردی باشد؟
                                فقط چیزی را عوض کنید که واقعاً می‌خواهید رفتار مدل تغییر کند. چهار الگوی پرکاربرد:
                            

                            
    
                                
  • لحن و زبان خروجی: «پرامپت انگلیسی را کوتاه، دستورالعملی و بدون توضیح اضافه بنویس.»
    • 
                                
  • ساختار ثابت: «خروجی را در این بخش‌ها بده: Context، Task، Constraints، Acceptance Criteria.»
    • 
                                
  • محدودیت همیشگی: «هر فایل، کتابخانه یا فناوری که کاربر نام نبرده اضافه نکن.»
    • 
                                
  • مخاطب خاص: «پرامپت را برای یک ربات کدنویس بنویس که فقط به یک ماژول دسترسی دارد.»
    • 
                            

                            

                                هشدار:
                                متن شما جایگزین کامل دستور پیش‌فرض می‌شود، نه متن کمکی کنار آن. اگر قواعد ساختار
                                خروجی (کلیدهای JSON) را بردارید، این صفحه نمی‌تواند پاسخ مدل را بخواند و خروجی
                                ناقص یا بی‌معنی می‌شود. اگر مطمئن نیستید، خالی بگذارید یا دکمهٔ «درج نمونهٔ آماده»
                                را بزنید و فقط همان چند خط را عوض کنید.
